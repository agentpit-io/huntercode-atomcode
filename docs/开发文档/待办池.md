# 待办池 · HunterCode·AtomCode 发行版（HCA）

> 发现但当轮不做的问题都堆这里。P0 = 阻塞下一个里程碑；P1 = 该里程碑内要解决；P2 = 可延后。

## P0

| # | 问题 | 发现于 | 说明 |
|---|---|---|---|
| P0-1 | **Web 转发层必须对接 `/live` 而不是 `/chat`** | M0 §5 | `/chat` 不挂载 MCP 工具（实测模型可见 36 个工具，无 `mcp__*`；调用返回 `unknown or unmounted tool`）。`/live` 有 39 个含 3 个 MCP 工具。投研场景没有 MCP 等于没有行情 |
| P0-2 | **`/live` 不支持按请求指定 `working_dir`** | M0 §8 | `/live/message` 无该字段，取 daemon 全局当前目录。多用户 / 多工作区只能一个目录一个 daemon 进程。M1 要定部署形态 |
| P0-3 | **测试 key 额度不够跑 M2 的 A/B 评测** | M0 §3 | 300k token/日，单轮对话固定开销 16.3k（系统提示 + 36 个工具 schema）。评测 30 轮约 480k。**需要用户决定** |
| P0-4 | **SKILL 的 `needs_tools` 与 AtomCode 工具名不同构** | M0 §6 | SKILL 写 `uzi_stock_deep_analysis`，AtomCode 是 `mcp__uzi__stock_deep_analysis`。转换器要做名字映射 |
| P0-5 | **hunter 系 MCP 的用户身份注入没有对应机制** | M0 §5 | 6 个 MCP 从工具参数取 `_hermes_user_id`，由 opencode 插件注入。AtomCode 无等价插件点。候选方案：PreToolUse hook 改参数（`hookSpecificOutput.updatedInput`），或 `.mcp.json` 里配 `env.HUNTER_USER_ID`（单用户工作区）。M2 定 |

## P1

| # | 问题 | 发现于 | 说明 |
|---|---|---|---|
| P1-1 | `plan` 档拦不住 bash 的写行为 | M0 §4 | `plan` 只拦 write_file / edit_file / search_replace / parallel_edit_files，工作区内 bash 照跑（`echo x > file` 能落盘）。"只读研究模式"必须靠 hook 补 bash 拦截 |
| P1-2 | `accept_edits` 对工作区外的写也不弹权限 | M0 §4 | 源码里 accept_edits 的判断排在 in_workspace 之前。不能把 accept_edits 当"项目内自动、项目外确认" |
| P1-3 | `GET /skills` 丢掉 `hunter:` 扩展字段 | M0 §6 | 只回 `{name, description}`。前端技能卡片要的 `display_name` / `icon` / `category` / `prompt_tpl` 得自己读 `SKILL.md` 或由 api 提供 |
| P1-4 | 技能斜杠命令没有 daemon 端点 | M0 §6 | `/command` 只有 12 个内置命令；`/live/command` 在 headless 下恒 `{"accepted":false}`。只能把 `/技能名 参数` 当普通消息发 |
| P1-5 | 单轮固定 token 开销 16.3k | M0 §3 | 系统提示 + 36 个工具 schema。投研会话大多用不到 `atomgit_*` / `code_review` / `trace_*`，但 AtomCode 没有工具白名单配置项。影响成本与上下文预算 |
| P1-6 | MCP 工具默认每次调用都弹权限 | M0 §5 | 需在 `.mcp.json` 配 `autoApprove` 或 `trust: true`。发行版模板要预置，否则用户每问一句行情都要点确认 |
| P1-7 | 项目级 `.mcp.json` 有信任门 | M0 §5 | 未信任的项目里 server 根本不连（`blocked: untrusted project`）。安装脚本要么写 `~/.atomcode/mcp.json`（不受限），要么装完自动 `POST /live/mcp/trust` |
| P1-8 | 美国测试机访问东方财富间歇失败 | M0 §5 | akshare 默认的 `stock_zh_a_hist` 走东方财富，测试机连了十来次后被拒。新浪源 `stock_zh_a_daily` 可用。测试用例优先选新浪源，或在报告里标注 |
| P1-9 | daemon 只能绑 127.0.0.1 | M0 §1 | 5.1.0 的 `daemon` 子命令没有 `--host`。compose 里 web/api 要访问 daemon，得同容器回环或加 sidecar 反代。M1 要定 |
