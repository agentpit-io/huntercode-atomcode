## 这个工作区是干什么的

这是一个**证券投研**工作区，不是代码仓库。这里的文件是研究资产：

| 目录 | 放什么 |
|---|---|
| `holdings/` | 持仓与交易记录 |
| `theses/` | 投资论点（每只票一份，记录买入理由与证伪条件） |
| `factors/` | 因子定义与回测结果 |
| `reports/` | 生成的研究报告 |
| `scripts/` | 一次性的量化脚本（Python 3，依赖见 `requirements.txt`） |

## 硬规则

1. **不许编数字。** 行情、财务、龙虎榜、资金流——一律通过 MCP 工具取。
   工具取不到就说取不到，并说明原因；**不要用记忆里的数字补位，也不要给"示例数据"**。
2. **每个数字都要能追到来源**：哪个工具、哪个函数、什么日期。
3. 本工作区的产出是**研究材料，不是投资建议**。涉及买卖判断时保留不确定性，
   写清楚证伪条件。
4. 用中文回答。

## 可用的数据工具

见 `.mcp.json`。取 A 股行情优先用 `mcp__akshare__akshare_call`；
它有 1000+ 个 AKShare 函数，先用 `mcp__akshare__akshare_search` 搜，
再用 `mcp__akshare__akshare_signature` 看参数，最后调用。

## 技能

`.atomcode/skills/` 下有 6 个投研技能（由 `tools/build_skills.py` 从仓库 `skills/` 生成）。
用户问到深度分析、评审团、龙虎榜、杀猪盘、风险画像时，用 `use_skill` 调对应技能。
